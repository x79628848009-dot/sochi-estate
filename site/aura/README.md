# site/aura — манифест системы (aura.sochi.estate)

Одностраничный манифест: не продукт и не каталог, а система, застигнутая за работой.
Тексты — канонические, менять только по решению основателя.

**Стек:** чистый HTML/CSS/JS. Ноль зависимостей, ноль сборки, ноль внешних загрузок
(шрифты системные, вся графика — CSS/SVG, фотографий нет). Вес страницы ~40 КБ.

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка, тексты, SEO/OG-теги |
| `styles.css` | Тёмная глубина `#0a0f1a` + янтарный `#e9a94d`, типографика, мобильная вёрстка, все анимации |
| `app.js` | Печать журнала, часы, азимут луча. Первая строка файла — единственная настройка: адрес CTA |
| `og.png` | Превью для соцсетей 1200×630 (сгенерировано из SVG, не фотография) |
| `favicon.svg`, `robots.txt`, `sitemap.xml`, `CNAME` | Служебное |

## Живёт ровно четыре движения (Часть X канона: «данные — это эстетика»)

1. Радар — луч (12 с на оборот) + расходящиеся кольца + дыхание колец.
2. Цели вспыхивают строго в момент прохода луча (цикл 36 с — три оборота, поэтому редко).
3. Журнал печатается посимвольно, курсор мигает.
4. Часы и азимут тикают. Азимут — реальный угол луча, снятый с той же анимации.

Параллаксов, частиц и анимаций по скроллу нет сознательно.
При `prefers-reduced-motion: reduce` всё движение выключается, содержимое остаётся полным.

## Правила честности

Ни одной выдуманной цифры. Строки журнала описывают механику, а не результаты;
под терминалом — подпись «визуализация работы системы». Число в строке про лоты за ночь
намеренно оставлено многоточием.

## Как поменять адрес кнопки

`app.js`, константа `CTA_LINK` в начале файла. Для Telegram:
`var CTA_LINK = 'https://t.me/ВАШ_НИК';`
