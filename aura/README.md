# aura/ — манифест системы (www.sochi.estate/aura)

Одностраничный манифест: не продукт и не каталог, а система, застигнутая за работой.
Тексты — канонические, менять только по решению основателя.

**Стек:** чистый HTML/CSS/JS. Ноль зависимостей, ноль сборки, ноль внешних загрузок
(шрифты системные, вся графика — CSS/SVG, фотографий нет). Вес страницы ~40 КБ.

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка, тексты, SEO/OG-теги |
| `styles.css` | Тёмная глубина `#0a0f1a` + янтарный `#e9a94d`, типографика, мобильная вёрстка, все анимации |
| `app.js` | Печать журнала, часы, азимут луча. Первая строка файла — единственная настройка: адрес CTA |
| `og.png` | Превью для соцсетей 1200×630 (сгенерировано из SVG, не фотография) |
| `favicon.svg` | Знак: объект в разомкнутом кольце ауры. Кольцо одно — двух на 16 px не видно, сливаются |
| `sitemap.xml` | Служебное |

## Живёт ровно пять движений (Часть X канона: «данные — это эстетика»)

1. Радар — луч (12 с на оборот) + расходящиеся кольца + дыхание колец.
2. Цели вспыхивают строго в момент прохода луча (цикл 36 с — три оборота, поэтому редко).
3. Журнал печатается посимвольно, курсор мигает.
4. Часы и азимут тикают. Азимут — реальный угол луча, снятый с той же анимации.
5. Радар отзывается в журнале: на вспышке цели маркер `›` одной из строк загорается
   на 2 с. Фаза берётся у самой анимации луча, поэтому подсветка не разъезжается
   со вспышкой (`schedulePings` в `app.js`, тайминги дублируют задержки целей в CSS).

Параллаксов, частиц и анимаций по скроллу нет сознательно.
При `prefers-reduced-motion: reduce` всё движение выключается, содержимое остаётся полным.

## Правила честности

Ни одной выдуманной цифры. Строки журнала описывают механику, а не результаты;
число в строке про лоты за ночь намеренно оставлено многоточием.

Статус «система строится» проговорён трижды: в надбровье героя, в заголовке терминала
(«демонстрация») и подписью под ним («так система будет вести журнал каждого объекта»).

## Как поменять адрес кнопки

`app.js`, константа `CTA_LINK` в начале файла. Сейчас — `mailto:michael@rovensky.ru`.
Для Telegram: `var CTA_LINK = 'https://t.me/ВАШ_НИК';`

## Деплой

Страница лежит в корне репозитория, потому что GitHub Pages публикует корень целиком —
папка `/aura` и есть адрес `www.sochi.estate/aura`. Отдельная сборка не нужна: файлы
отдаются как есть, ссылки между ними относительные.

Публикация происходит слиянием ветки в ветку по умолчанию (её и раздаёт Pages).
Это human-gate: сливает основатель.

Если позже переезжаем на поддомен `aura.sochi.estate` — папка переносится в корень
отдельного репозитория без единой правки кода. Меняются только четыре абсолютных
адреса в `<head>` (canonical, og:url, og:image, twitter:image) и `loc` в `sitemap.xml`,
и добавляется файл `CNAME`.
