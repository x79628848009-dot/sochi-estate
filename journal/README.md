# journal/ — журнал событий реальных объектов

**Критерий истины проекта.** Пока не поднята база Supabase (Этап 1 промпта), журнал ведётся файлами: один объект = один файл `OBJ-001.md` (нумерация сквозная, без адресов в имени).

Формат события (append-only, новые сверху не переставлять — только добавлять вниз):

```
## 2026-08-04 14:30 · source: founder · type: intake
Объект принят в систему. Анкета заполнена на 80%, ждём выписку ЕГРН.
confidence: high · основание: анкета собственника
```

Обязательные поля: дата-время, источник, тип события, обоснование/первоисточник.
Типы: intake · egrn · analysis · legal · strategy · content · publication · telemetry · lead · negotiation · decision · correction · deal · archive.

При переезде в Postgres эти файлы импортируются в таблицу events — формат совместим сознательно.
