# AURA · sochi.estate

**Объект недвижимости становится субъектом рынка и продаёт себя сам — в обвязке агентов.**

Первая система, где у объекта есть цель, память, голос и стратегия. Плацдарм — Сочи. Полное описание проекта — в каноническом документе: **[research/AURA_MASTER.md](research/AURA_MASTER.md)** (начните с Раздела 0.3 — сводка на одной странице).

---

## Карта репозитория

| Папка | Назначение | Правило |
|---|---|---|
| `research/` | **Мышление проекта.** Канон (AURA_MASTER.md), архив исходников, рабочие исследования | Канон меняется только через changelog |
| `docs/` | **Продуктовые артефакты для внешнего мира:** презентация (PITCH.md), офферы, лендинг-тексты | Всё, что показываем людям |
| `cartridges/` | **Картриджи территории:** юр-граф Сочи (антитела), профили площадок | Ядро не содержит ничего локального — вся локальность здесь |
| `journal/` | **Журнал событий реальных объектов** — критерий истины проекта | Append-only; здесь живёт доказательство, не мнения |
| `/aura` | Манифест системы (sochi.estate/aura) | Тексты — канон, менять только решением основателя |
| `.claude/` | Субагенты и команды Claude Code (обвязка) | Строится по промпту Части XII канона |
