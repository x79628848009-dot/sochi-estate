# cartridges/ — картриджи территории

Вся локальность проекта живёт здесь. Ядро (агенты, логика, сайт) не содержит ничего сочинского.

- **sochi-legal/** — юридический картридж: антитела юр-графа Сочи. Формат: YAML `триггер → проверка → диагноз → протокол лечения`. Каждый обработанный объект с новой «миной» добавляет антитело.
- **ru-channels/** — канальный картридж: профили площадок (Авито, Циан, Домклик, Яндекс): факторы ранжирования, лимиты, форматы, правила ToS (по итогам аудита R-3).

Выход на новый рынок = новая пара картриджей, не изменение ядра (Часть VII канона).
