# research/ — мышление проекта

Здесь живёт всё, что проект думает: канон, исходники, рабочие исследования.

- **AURA_MASTER.md** — единственный источник истины (v4.0). Изменения — только через changelog в Разделе 0.6.
- **archive/** — исходные материалы концептуальных сессий (PDF ранних версий, черновики). Только для истории, в работе не используются.
- **notes/** — рабочие исследования текущей фазы. Одна тема = один файл, имя: `YYYY-MM_тема.md`. Каждый факт — со ссылкой на источник. Подтверждённые выводы переносятся в канон или в картриджи.

## Очередь исследований (Фаза 1)
1. `2026-08_tos-audit.md` — аудит правил Авито/Циан/Домклик/Яндекс: автоответы, действия за собственника, парсинг (риск R-3, блокирует горячий контур)
2. `2026-08_egrn-providers.md` — сравнение API-провайдеров ЕГРН: цены, полнота, скорость
3. `2026-08_passport-pricing.md` — ценообразование Паспорта: чек юр-проверок на рынке, готовность платить (тесты T1–T4, риск R-1)
